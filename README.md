# MDI Mosaic

Mosaic is an MDI and MDI-3D based Java application for computing and visualizing
the intersection of a Cartesian GSM grid with a spherical grid centered on Earth.

The project uses Geocentric Solar Magnetospheric (GSM) coordinates and Earth
radii as its natural length unit.

## Current Status

Early application skeleton:

- Maven Java project
- MDI application shell
- Grid setup dialog
- Mosaic grid data model
- Model changed listener support
